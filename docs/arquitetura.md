# Arquitetura do Assinator2000

Documentação técnica da arquitetura do sistema Assinator2000.

## Componentes

- Frontend: HTML, CSS e JavaScript
- Backend: Cloudflare Pages Functions / Workers
- Banco de dados: Cloudflare D1
- Documentos: Microsoft SharePoint
- Integração: Microsoft Graph

A arquitetura será documentada conforme o desenvolvimento do projeto avançar.
